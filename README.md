# StockLab

AI株式分析と株式投資シミュレーションを組み合わせる学習用Webアプリです。

## MVP（初期版）
- 仮想資金100万円からスタート
- サンプル銘柄の仮想売買（1株単位）
- 保有銘柄・仮想現金・評価損益の表示
- ブラウザの localStorage に状態を保存
- 企業分析で確認する基本項目を表示

## 起動方法
```text
index.html をブラウザで開く
```

ビルドツールやAPIキーは不要です。

## 重要な注意
- 表示価格・騰落率はUI確認用の架空サンプルです。リアルタイム株価ではありません。
- AI分析APIや外部市場データ連携はまだ実装していません。
- 実際の金融商品取引・証券口座との接続は行いません。
- 仮想取引の状態は利用中のブラウザ内に保存されます。
